curl实践

发表于2026-11-07|更新于2026-11-07
|浏览量:

实验目的

  1. 掌握 curl 基础用法，理解 GET、HEAD、POST、重定向等 HTTP 请求，看懂请求与响应报文。

实验环境

  • 虚拟机：Debian 12.x 64位
  • 网卡模式：NAT（支持外网访问）
  • 测试目标：外网目标：https://httpbin.org（公共HTTP调试站点）

前置检查

检查 curl 是否存在：
ash curl --version

外网测试

使用公共测试服务，[httpbin.org](https://httpbin.org) 进行 POST、重定向等进调试。

  1. GET请求，仅输出响应正文
    curl https://httpbin.org/get
  2. -i 同时输出响应头、响应体
    curl -i https://httpbin.org/get
  3. -I HEAD请求，只获取响应头
    curl -I https://httpbin.org/get
  4. POST 表单提交
    curl -X POST -d "username=test&password=123456" https://httpbin.org/post
  5. POST JSON数据
    curl -X POST -H "Content-Type: application/json" -d '{"name":"debian","id":1001}' https://httpbin.org/post
  6. -L 小写L：自动跟随301/302重定向
    curl -L https://httpbin.org/redirect/1

curl实践

实验目的

  1. 掌握 curl 基础用法，理解 GET、HEAD、POST、重定向等 HTTP 请求，看懂请求与响应报文。

实验环境

  • 虚拟机：Debian 12.x 64位
  • 网卡模式：NAT（支持外网访问）
  • 测试目标：外网目标：https://httpbin.org（公共HTTP调试站点）

前置检查

检查 curl 是否存在：
ash curl --version

外网测试

使用公共测试服务，[httpbin.org](https://httpbin.org) 进行 POST、重定向等进调试。

  1. GET请求，仅输出响应正文
    curl https://httpbin.org/get
  2. -i 同时输出响应头、响应体
    curl -i https://httpbin.org/get
  3. -I HEAD请求，只获取响应头
    curl -I https://httpbin.org/get
  4. POST 表单提交
    curl -X POST -d "username=test&password=123456" https://httpbin.org/post
  5. POST JSON数据
    curl -X POST -H "Content-Type: application/json" -d '{"name":"debian","id":1001}' https://httpbin.org/post
  6. -L 小写L：自动跟随301/302重定向
    curl -L https://httpbin.org/redirect/1

zoom eye信息搜集学习

搜索引擎

概念区分

普通搜索引擎（百度、谷歌）：抓取网页内容；
网络测绘搜索引擎（ZoomEye/FOFA）：探测IP、端口、服务指纹，收录联网硬件与Web资产。

国内测绘引擎

  1. ZoomEye（钟馗之眼｜知道创宇）
    • 双引擎：Xmap主机探测 + Wmap Web指纹识别
    • 优势：国内资产覆盖好，支持历史资产查询
    • 语法示例：app:nginx port:443 site:test.com
  2. FOFA（白帽汇）
    • 优势：更新快，支持icon图标检索，国内站点收录丰富
    • 语法示例：app="nginx" && port="443"
  3. Quake鹰图（360）
    • 优势：物联网、工控设备识别，资产关联分析

国外测绘引擎

  1. Shodan：全球老牌设备测绘引擎，工控、IoT设备多，国内资产覆盖一般
  2. Censys：证书情报强项，适合基于SSL证书收集子域名

用途总结

这类引擎可以作为OSINT公开情报源，利用site/domain语法被动获取引擎已收录的子域名，是子域名收集的手段之一。

zoomeye实践

记录①：xssq.guet.edu.cn:443

  • 完整子域名：xssq.guet.edu.cn
  • 端口与协议：443（HTTPS）
  • 地理位置：中国广西桂林，运营商：中国电信
  • HTTP响应状态：HTTP/1.1 302 Moved Temporarily
  • 快照时间：2026‑11‑05 07:23

记录②：www.guet.edu.cn:443

  • 完整子域名：www.guet.edu.cn
  • 端口与协议：443（HTTPS）
  • 地理位置：中国广西桂林
  • HTTP响应状态：HTTP/1.1 200 OK

域名层级分析

  • 根域名：guet.edu.cn
  • 子域名示例：
    • www.guet.edu.cn：学校官网二级子域名
    • xssq.guet.edu.cn：学校另一业务二级子域名

可以看出同一机构根域名guet.edu.cn下，存在多个不同前缀的子域名，分别承载不同业务系统。
查询：桂林电子科技大学
org=”桂林电子科技大学”

查询：桂林电子科技大学的端口4430的资产
org=”桂林电子科技大学” && port=”4430”

子域名查询

根域名：qq.com
子域名：
——download.sj.qq.com（三级）
——ycg.qq.com（二级）
——labi.qq.com（二级）
——music.qq.com（QQ音乐，二级）
——v.qq.com（腾讯视频，二级）
——mail.qq.com（QQ邮箱，二级）
…….

域名层级关系

根域名：qq.com
二级子域名：music.qq.com
结构说明：music 为子域名前缀，拼接根域名形成完整二级子域名 music.qq.com
业务含义：QQ音乐官方站点

拓展多级子域名对比

  1. 二级子域名：music.qq.com、ycg.qq.com
  2. 三级子域名：download.sj.qq.com（两层前缀嵌套）

知识点总结

  1. 根域名qq.com前面增加合法前缀即可生成子域名，支持多层嵌套（二级、三级甚至更深）
  2. ZoomEye site:根域名语法是被动批量收集子域名的核心语法
  3. 提取子域名时，需要剥离端口后缀，只保留完整域名
  4. 大型企业根域名下存在大量承载不同业务的多级子域名，子域名收集是网络攻击面测绘的基础环节

信息安全等级保护2.0

信息安全等级保护 2.0

为什么要有等保

系统重要程度不同，不能”一刀切”。按重要性分等级，等级越高安全投入越多。

[!info] 核心逻辑
银行被黑 vs 论坛被黑，后果完全不同 → 区别对待，分级保护。

五个等级

等级 通俗理解 举例
一级 自己看着办 个人博客
二级 建议做 企业官网、学校系统
三级 必须做 银行、政务
四级 极严格 关键基础设施
五级 最高级别 军工、核设施

记忆技巧

常见系统大多是 二级或三级。三级以上强制，二级自愿。

2.0 vs 1.0 升级在哪

变化 通俗理解
对象扩大 增加云、大数据、物联网、移动互联、工控
更灵活 通用要求 + 扩展要求
持续防护 动态监测，不是测完就完
可信计算 关键环节防”偷梁换柱”

一句话总结

1.0 是”修墙”，2.0 是”装监控+报警器+巡逻队”。

🛠️ 五步流程

flowchart LR
    A[定级] --> B[备案] --> C[建设整改] --> D[等级测评] --> E[监督检查]
